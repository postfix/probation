## Acceptance obligations derived from source facts

For every family: exact allow/hold/block, no substitution, cold/warm cache, restart/first-seen, integrity failure, same policy on direct artifact and auxiliary version-bearing files, HEAD/Range where supported, requested-origin traces and no alternate-origin retry. Add family-specific cases from the table: Maven classifier/SNAPSHOT/metadata checksums; Go mod-before-zip/escaping/sumdb/fallback; Cargo aliases/index checksum; NuGet pagination/nuspec/resource URLs; CPAN author collisions/sidecars; gems platform ambiguity/Bundler routes; Conan new binary revision on old recipe; OCI index/child/direct digest/blob/tag changes.

Nora's eight handlers do not provide complete per-version discovery filtering. A port must add it where the protocol exposes candidates; a pass-through discovery document is not proof of the product's older-eligible-version behavior. Artifact enforcement remains mandatory independently.
