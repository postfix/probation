Slice 16 (FIX-16-A): current managed authority and OSV generation checked before any artifact release

Delivered

When a managed (service-policy) install asks for an npm or PyPI artifact, on the legacy and selected-registry routes, the release is now gated. Before bytes are released, the synchronous publication gate checks that managed authority is still current. It also checks that the OSV generation is the one the decision was made against. If OSV generation changed after the decision was prepared, the request is refused, and the refusal covers both cold and warm cache paths. The gate refuses on the first generation change; the design text allowed one re-evaluation first (C-S16-2, resolved: the design test table accepts "re-evaluated or refused"). Standalone mode (no managed/service policy) has no gate by design (C-S16-4, resolved).

The evidence records that at HEAD 6c4b7fc a prototype gate already existed in src/managed/service_policy.rs. This slice moved it and completed it. The evidence does not describe the prior release behavior beyond that.

Changes, each a new or changed declaration or file:

  • src/managed/publication_gate.rs (new file): the gate, moved out of src/managed/service_policy.rs, which re-exports it. It adds respond_order (the synchronous guard that refuses after publication and when poisoned), the barrier test hook, poison handling and pending-writer tests.
  • src/osv/mod.rs: OsvCache.generation, bumped in put only when the value is a match and there is no live match (C1029). This is the "osv_generation" the gate binds.
  • src/artifacts/mod.rs and src/artifacts/stream.rs: the wiring, including authority.with_osv(..).
  • src/managed/mod.rs: changed in the working tree; its change is not detailed in the evidence.
  • tests/managed_release_wiring.rs (new, 6 tests).

Row 16 lists src/lib.rs, src/osv/batcher.rs and the http route files, but they did not change. The generation counter lives in OsvCache (C-S16-3, resolved; plan text only). Mechanical churn: none recorded. No signature change outside the items above is claimed.
