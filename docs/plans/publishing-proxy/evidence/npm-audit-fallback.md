# npm audit fallback investigation

The pinned npm 11.21.1 client sends a gzipped bulk request containing a map of package names to installed version arrays. Its installed `@npmcli/arborist/lib/audit-report.js` `#getReport` posts only to `/-/npm/v1/security/advisories/bulk`; on 404 it records the error and returns without calling quick audit. The selected E2E counted the same one upstream bulk request and no quick request. The pinned image and exact trace are recorded in [Slice 3 evidence](slice-3.md).

The [npm audit command documentation](https://docs.npmjs.com/cli/v11/commands/npm-audit/) describes a quick fallback and says its request includes the full `package-lock.json` dependency tree and platform metadata. That document conflicts with the installed npm 11.21.1 code and observed client behavior for the fallback itself, but confirms that quick needs more information than the bulk request carries.

The [npm 11.21.1 Arborist source](https://github.com/npm/cli/blob/v11.21.1/workspaces/arborist/lib/audit-report.js#L317-L384) confirms the observed Bulk-only request. The [npm 11 changelog](https://github.com/npm/cli/blob/v11.21.1/CHANGELOG.md) records removal of the old Quick fallback. The [npm 10.9.4 Arborist source](https://github.com/npm/cli/blob/v10.9.4/workspaces/arborist/lib/audit-report.js#L1678-L1726) constructs a Quick request from the complete tree and runtime metadata; its [response conversion](https://github.com/npm/cli/blob/v10.9.4/workspaces/arborist/lib/audit-report.js#L275-L301) can map valid Quick advisories to Bulk-style package arrays.

The proxy cannot reconstruct the original dependency tree, aliases, dependency edges, omitted types and platform metadata from a bulk name/version map. Forwarding that map to quick would violate the documented quick request contract; fabricating a tree could produce incomplete or misleading vulnerability results. Returning an empty success response would falsely report no vulnerabilities. A general transparent Bulk-to-Quick translation is therefore not a truthful support claim.

After clarification on 2026-10-27, the product remains a proxy. Probation forwards npm 11's bulk request to the selected registry and filters a successful response. If that registry does not support bulk, npm receives the registry error. Clients that send a valid quick request directly can use the guarded quick route. Probation does not create an advisory service or fabricate a quick request from incomplete bulk data. This is the N04 scope decision, and the release matrix must show the unsupported-upstream outcome explicitly.
