## Implementation

- Local-service dispatch opens the existing named npm handlers and preserves separate whole-package, direct canonical tarball and opaque-reference DELETE branches. Whole-package DELETE is upstream-authorized without a version marker; direct canonical DELETE refuses locally.
- Unpublish leases use owner zero in the existing data-directory store, independent of policy account/place and developer credential. Historical membership IDs are generated positive identities (`crates/probation-server/migrations/0001_init.sql:94`); historical lease preparation rejects zero. A distinct service AEAD associated-data prefix prevents importing old member-zero ciphertext as a service destination. Existing registry partitioning, immutable opaque reference identity, lifetime, URL validation and transaction quotas remain in use.
- `service_unpublish.rs` verifies accepted exact leased-version removal, takes a valid PUT response revision or immediately fetches selected-upstream metadata with the same developer credential, and requires the version absent plus a valid resulting revision. It then durably commits service/registry/reference/revision markers. Denied and unchanged PUTs do not mark; unverifiable accepted writes and marker commit failure return the existing `PARTIAL_WRITE_UNCERTAIN` HTTP 503 result.
- The reference path checks the service store, registry, filename, package/version record, decrypted destination and current selected-origin D41 scope. It atomically consumes the matching revision marker before transport sends. Selected-origin-only approval applies both before advertising a write URL and before DELETE. Extra-origin bearer settings cannot widen the local-service path.
- Historical action scenario entry points now explicitly import the preserved certificate-era function. Dependent read tests retain tokenless refusal/zero-I/O and unknown-route assertions while supported actions are covered by the active action scenario.
- Code-review regression repaired test-first: URI guards had given encoded scoped package text to the existing already-decoded name validator. A private URI-package guard now uses the same already locked percent-encoding 2.3.2 decoder family as Axum, checks UTF-8 strictly, and validates exactly once without changing outgoing routing bytes. Cargo adds only a direct dependency edge to that existing exact version. Scoped HTTP positives and malformed/double-encoded zero-I/O controls pass; the native npm scenario now also publishes, deprecates, version-unpublishes and whole-unpublishes a scoped package.
