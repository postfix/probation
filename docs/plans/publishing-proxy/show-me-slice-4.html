Limits

  • The pinned npm end-to-end run used fake upstreams. Compatibility with every real registry is untested; an upstream that does not support unpublish can still refuse it.
  • npm logout removes this registry’s certfile/keyfile settings, so a later tokenless request needs the setup bundle re-run before certificate admission.
  • For a stalled upstream response, the gateway closed the client connection within the test bound; the client did not receive an HTTP 504. The later request succeeded, showing the permit was released.
  • Exact external issuer integration and Python client workflows remain Slice 5 scope. Broad SMTC guard and persistence analysis was incomplete and was not counted as clean proof.
