What problem do we have?

Company admins need to configure several npm and Python registries, including private ones. Projects must select the intended registry; private downloads need a shared read-only connection, and the admin decides whether new releases wait under policy or install immediately.

How will we solve it?

  • Add a registry → name, ecosystem, address, optional read-only download credential, and explicit trust choice.
  • Review configured registries → see package ecosystem and new release rule.
  • Handle a failed connection → correct the address or download connection and try again; no registry was added.
  • Remove a registry → warn that projects lose access until they select another; no silent fallback.
