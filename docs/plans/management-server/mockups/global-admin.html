A range an org admin adds does nothing until you approve it. From an approved range, Probation refuses every key that is not the organisation's own, so check the range really is that organisation's office or VPN.

The network lock is a secondary control. Phone networks and country-wide address sharing put unrelated people behind one address, so a range cannot identify a company on its own. Approving such a range would refuse everyone else's keys there.
