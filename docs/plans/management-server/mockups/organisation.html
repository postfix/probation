Organisation: Acme

Only Acme's org admins see this screen. Acme can have several org admins and always keeps at least one. "Reset authenticator" helps a member who lost theirs and has no backup codes. You can reset it only for a member whose login belongs to Acme alone (no personal account, no other organisation). Everyone else's, and any org admin's, is reset by the service operator.

Network lock

From the addresses listed here, Probation refuses every key that does not belong to Acme (for example someone's personal account key or another organisation's key).

A range you add does nothing until the service operator approves it, so no organisation can lock out another one's people.

"192.0.2.300/24" is not a valid IP range.

The network lock is a second line of defence; the main one is a locked device setup. Phone networks and some whole countries put many unrelated people behind one address, so an address cannot identify your company on its own. It also does not stop someone working off the network without a locked device setup.

State: network lock, empty (off, the default)

The network lock is off: no IP ranges are registered. Add your office and VPN ranges to turn it on; each range works once the service operator approves it.
