What the layer below may loosen

These switches decide what each member of Frontend may do in their own policy.

At the user layer and in a personal account there is no layer below, so these switches are not shown. At the platform layer one set of switches governs every organisation and every personal account alike.

You can only pass down what Acme allows you. Greyed-out switches are ones Acme does not allow Frontend.

An exception to a block set higher up needs every layer between the block's owner and you to allow exceptions. Here: Platform lets Acme, and Acme lets Frontend.

Changes reach every firewall within about 1 minute.
