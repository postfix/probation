API keys

An API key lets npm or pip download through Probation. Every key belongs to the place selected at the top (here: Acme), and that decides which rules apply to every download made with it.

Service keys

A service key belongs to Acme, not to a person, so it keeps working when people leave. Every download made with it gets the policy of the group (or of the organisation) it is attached to. Push it to company devices with your device management tool (for example Intune).
